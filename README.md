# Tugas-Akhir
Codingan Arduino IDE sensor yang digunakan dalam penelitian, penelitian ini menggunakan ADC external yaitu ADS1115 untuk pembacaan ADCnya lebih akurat, artinya codingan karakterisasi tidak menggunakan ADC eksternal. Karena penggunaan sensor yang banyak mengakibatkan pembacaan sensor jadi fluktuatif.
