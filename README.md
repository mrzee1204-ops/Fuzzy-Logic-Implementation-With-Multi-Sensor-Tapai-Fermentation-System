# Undergraduate-Thesis
Codingan Arduino IDE sensor yang digunakan dalam penelitian, penelitian ini menggunakan ADC external yaitu ADS1115 untuk pembacaan Analognya lebih akurat, artinya codingan karakterisasi tidak menggunakan ADC eksternal. Karena penggunaan sensor yang banyak dan koneksi terhadap Wi-Fi mengakibatkan pembacaan sensor jadi fluktuatif dan menjadi tidak akurat.
Repository ini diharapkan bisa membantu bagi pembaca untuk mengembangkan alat dengan fungsi yang sama agar lebih efektif dan efisien dalam penerapannya.
